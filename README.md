# YP_DiplomProject_Autotests_and_SQL
  ## Работа с базой данных

### Задание 1
#### Проверка отображения заказа в базе данных

Представь: тебе нужно проверить, отображается ли созданный заказ в базе данных.

Для этого выполни следующие действия:

* Выведи список логинов курьеров с количеством их заказов в статусе «В доставке» (поле inDelivery = true).

* Примеры запросов находятся в файле [sql_queries](sql_queries.sql)

* Результаты можно посмотреть на скриншоте [Запросы к БД](Запросы к БД.jpg)

### Задание 2
#### Тестирование статусов заказов

Ты тестируешь статусы заказов. Нужно убедиться, что в базе данных они записываются корректно.

Для этого выполни:

* Выведи все трекеры заказов и их статусы

* Статусы определяются по следующим правилам:
  * Если поле finished == true, то статус: 2
  * Если поле cancelled == true, то статус: -1
  * Если поле inDelivery == true, то статус: 1
  * Для остальных случаев: 0

* Примеры запросов находятся в файле [sql_queries](sql_queries.sql)

* Результаты можно посмотреть на скриншоте [Запросы к БД](Запросы к БД.jpg)

## Автоматизация теста к API

### Сценарий тестирования

Подготовка: коллеги-тестировщики подготовили следующий сценарий:
* Клиент создает заказ
* Проверяется возможность получения данных о заказе по треку

### Шаги автотеста
* Выполнить запрос на создание заказа
* Сохранить номер трека заказа
* Выполнить запрос на получение заказа по треку
* Проверить, что код ответа равен 200
